# VIDEOS3D

Repositório para o fluxo **Cartoon 3D Short**: criação de vídeos verticais de aproximadamente 55–70 segundos, com personagens 2D em cenários 3D coloridos, renderizados com Three.js dentro do Remotion.

## Arquivos nesta primeira importação

- `SKILL.md`: instruções do fluxo, pipeline, parâmetros visuais, áudio, renderização e QA.
- `LICENSE`: licença MIT recebida junto ao pacote original.

## Dependências previstas

- Node.js
- Remotion e `@remotion/three`
- Python 3
- FFmpeg

## Situação da importação

Esta primeira etapa registra a documentação principal do pacote. Os templates de código e os recursos visuais ainda não foram transferidos para este repositório. As imagens de referência privadas do pacote original não devem ser republicadas.

Consulte `SKILL.md` para os requisitos e o fluxo de trabalho.
